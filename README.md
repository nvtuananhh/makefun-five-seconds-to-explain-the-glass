Entry for the make.fun bounty [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949).

## The entry

> That glass sat in my sunbeam for four hours, so I relocated it to the floor, where it now enjoys considerably more space.

## What main.py does

`main.py` (Python 3, standard library only, no network) writes that single
sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `.`), followed by a
newline. It asserts the entry is 1–200 characters (exactly 121), a single
line, and not only whitespace — the bounty gate — and is fully deterministic:
the same sentence on every run.

## Why it fits the brief

- **Cat's own logic, zero remorse:** the glass is not knocked over, it is
  "relocated" — a bureaucratic euphemism, as if the cat did the glass a favour.
- **Fresh comic idea:** the joke is not gravity or a slippery edge; it is a
  property dispute over the sunbeam, settled by eviction.
- **Fits the five seconds:** one spoken sentence, no reasoning paragraph, with
  the punchline ("considerably more space") landing in the final words.

## Run it

```sh
python3 main.py
cat entry.txt
```
